# 🌍 Explorer — Adventure Website

A responsive travel and adventure website built with **React** and **React Router v6**. Features a dynamic navbar, hero section with video background, and an interactive cards showcase.

---

## 🚀 Live Demo

> Run locally at `http://localhost:3000`

---

## 📸 Features

- ✅ Responsive Navbar with mobile hamburger menu
- ✅ Hero section with autoplay background video
- ✅ Reusable Button component with multiple styles and sizes
- ✅ Cards section showcasing travel destinations
- ✅ Category label overlay on card images
- ✅ Smooth hover animations and transitions
- ✅ React Router v6 navigation

## ⚙️ Getting Started

### Prerequisites
Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v14 or higher)
- npm (comes with Node.js)

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/your-username/adventure-website.git
cd adventure-website
```

2. **Install dependencies**
```bash
npm install
```

3. **Install React Router**
```bash
npm install react-router-dom
```

4. **Start the development server**
```bash
npm start
```

5. **Open your browser** and navigate to `http://localhost:3000`
